# Slate's setups and coverage plans

`setups.json` (165 cinematography snippets in 12 groups) and `coverage-plans.json` (12 ways to cover a scene) are
from **Slate, the prompt studio for AI filmmaking, by Sam Wasserman (wassermanproductions.com)**, Apache-2.0, as
shipped in github.com/drowzeys/Imagination-Studio-by-keys-Wasserman at commit `ef88a07` (`app/static/slate/`).
They are copied unchanged; Slate's NOTICE is beside them. IV Studio's own code (`src/service/filmcraft.js`) reads
them: the Cinematography picker in Create and Projects, and coverage plans on the storyboard.
